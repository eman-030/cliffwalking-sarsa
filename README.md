## Objective

Train a tabular reinforcement learning agent to reach the goal in a 4-by-12 grid while avoiding costly cliff falls. SARSA is implemented from scratch using NumPy. The simulator is Farama Gymnasium's CliffWalking-v1 with non-slippery movement.

## Algorithm

SARSA updates the current state-action value using the value of the next action actually selected by its epsilon-greedy policy:

`Q[s,a] += alpha * (reward + gamma * Q[next_state,next_action] - Q[s,a])`

For true terminal transitions, the target is reward alone. A cliff fall resets position but does not terminate the episode. A 500-step time limit is explicitly applied; truncation ends a rollout but does not suppress the bootstrapped value.

## Experiment design

- Three constant training epsilon values: 0.01, 0.1, 0.3.
- Three training seeds per value: 30, 31, 32; 3,000 episodes each.
- Fixed alpha=0.5 and gamma=1.0.
- Every 500 episodes, validate for 100 episodes with evaluation epsilon=0.1 and action-generator seed 10000.
- Select the training epsilon with the largest final validation mean return averaged across the three training seeds. Retain its seed-30 Q-table.
- Final evaluation: 300 episodes each for greedy, epsilon=0.1 and uniform-random policies using a new action-generator seed 20000.
- Fixed start and deterministic transitions mean repeated greedy evaluations trace the same route; they are not distinct generalization tests.

The supplied notebook contains real executed outputs. Its preparation used sequential in-process IPython execution because that host does not allow Jupyter kernel sockets; the file remains a normal notebook runnable in Jupyter or VS Code.
